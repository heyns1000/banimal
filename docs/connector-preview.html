Admin screens, as built

wp-admin chrome, not the public brand skin
These render in WordPress's own admin styling — grey chrome, admin blue, native form fields — because that's what the PHP in PR #14 actually produces, and because plugin admin screens conventionally don't inherit a site's public brand. The Sam Fox™ / Banimal™ identity shows up on the public storefront and in the brand tokens the plugin injects into the public theme (via /api/brand-guide, added in PR #19) — not inside wp-admin itself.
